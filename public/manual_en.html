Getting Started

1. Login

Open the server URL in your browser and the login screen will appear. Enter the username and password provided by your admin, then click Login.

Your login session is kept for 30 days. On the same browser and device, you will be logged in automatically next time.
Character

2. Create a Character

To start chatting, you first need to create a character. There are three ways to do this.

🧙
Create with Wizard
A beginner-friendly method where you chat with an AI to decide gender, personality, appearance, clothing, and location step by step.
🖼️
Create from Image
Upload a reference image and the AI reads the appearance automatically. Just add personality and location to finish.
✏️
Direct Input (Advanced)
Directly fill in the form with name, personality, appearance, and more.

Create with the Wizard

Tap the character selection button at the bottom of the screen to open the character list. Then tap 🧙 Create with Wizard.

Once the wizard launches, the AI will ask you questions. Answer them in order — gender, personality, appearance, clothing, and location — and your character will be created automatically.

1
Choose gender Tap a button to select.
2
Answer personality, appearance, etc. Type freely. If the AI does not understand, it will ask again.
3
Done! An image is generated and your character is registered. You can start chatting right away.
After the wizard finishes, you can start an interactive tutorial. Highly recommended for first-time users.

Create from Image

Select 🖼 Create from Image from the character list to launch the image wizard.

1
Upload a reference image Tap "📁 Choose Image" and select an illustration or photo of the character you have in mind.
2
AI reads the appearance The AI automatically extracts hair, eyes, body type, clothing, and location from the image. Tap "Change something" to adjust any part.
3
Set personality and location Answer the AI's questions to describe the character's personality and usual setting.
4
Choose an icon When ComfyUI is connected, pick between the uploaded reference image and the generated image as the character icon.
5
Enter a name and finish Type a name and your character is registered.
The image wizard works even without a ComfyUI connection. In that case, the uploaded image is used directly as the character icon.

Direct Input (Advanced)

Select ✏ Direct Input (Advanced) from the character list, or tap an existing character once to open the edit form. You can directly enter name, personality, appearance, speaking style, and more.

Appearance fields require EN conversion
After entering text in the "Appearance (body)" and "Appearance (clothing)" fields in Japanese, press the EN Convert button next to the field. The AI translates it into an English prompt for image generation. Without converting, appearance will not be reflected in generated images.

How to Write Character Settings

Fields like "Personality" accept free text, but using the <tag=content> format helps the AI understand character settings more precisely. Writing {{user}} will be automatically replaced with the logged-in username.

Example personality field:
<personality=bubbly and carefree>
<likes=casting magic spells>
<location=a cottage in the forest>
<physical trait=very ticklish>
<background=lost both parents, lives alone; craves company despite her cheerful exterior>

Example opening message field:
{{user}}, you came! I'm Maho! I'm a witch — still practicing though!

You can add as many tags as you like. Keep them short and specific for best results.

Chat

3. Chat Basics

Select a character to enter the chat screen. Type your message in the input field at the bottom and press Send ▶ to start the conversation.

Writing Narration / Situation Text

Text wrapped in *～* within a message is treated as narration or situation description rather than dialogue. The AI will naturally interpret it as part of the scene.

Examples:
*knocks on the door*
*It had started to rain outside*
Hey, *while holding your hand*, will you stay with me?

Toggling Image Generation

Above the input field there is a 🎨 Generate / 💬 Chat Only button. Tap it to toggle. In "Chat Only" mode, no images are generated — text only.

Character-Led Mode

Press the 🎭 button to enter Character-Led Mode. The character will take initiative — speaking up and acting on their own. Press again to disable.

USER Focus

Press the 👤 button to enable USER Focus mode. Generated images will center on your own appearance rather than the character's.

Message Actions

Long-press a message (or right-click on PC) to open the action menu.

✏️
Edit Reply
Rewrite the character's reply directly.
🔄
Regenerate
Generate the character's response again.
🌿
Branch Here
Try a different story development from this turn.
🗑️
Delete
Delete this turn.

Image Actions (Right-click / Long-press)

Right-click an image in the chat (or long-press on mobile) to open the image action menu.

📋
View Prompt
View the Japanese and English prompts used to generate this image. Copying is also available.
✏️
Edit Prompt Directly
Manually rewrite the English prompt and regenerate. You can preview before applying the change.
⚓
Set as Anchor
Fix this image as the base for differential generation (see below).
🔄
Re-infer and Regenerate
The AI recalculates the prompt and regenerates the image.
🎲
Regenerate with New Seed
Keep the same prompt but use a different random seed to get a different result.

Anchor and Differential Generation

An "anchor" is an image used as the base for differential generation. Once set, subsequent images are generated by taking the anchor's English prompt and layering only the changes you input on top. Perfect for minor tweaks like changing clothing or expression.

1
Set an anchor Right-click the image you want as a base and choose "⚓ Set as Anchor", or press the ⚓ button and tap an image. The button becomes active when an anchor is set.
2
Enter only what changes and send Type just the change you want, e.g. "holding a flower in her right hand". The anchor prompt and your change are merged for generation.
3
Clear the anchor Press the ⚓ button again to clear it. Generation returns to normal afterward.
Photo Mode's "🔄 Diff" tab automatically uses the previous image as the base without needing to set an anchor. Use it when making a series of small continuous edits.
Photo

4. Photo Mode

Photo Mode lets you focus purely on image generation without chatting. Press the 📷 button to the left of the input field to start.

There are three mode tabs above the input field.

TL
Translate mode Enter a scene in Japanese and the AI translates it into an English prompt for generation.
Δ
Diff mode Enter only what changes from the previous image. Good for light edits like "change the pose".
EN
Direct input Enter an English prompt directly. No AI translation is performed.

Generated images are displayed in a carousel at the top of the screen. Swipe horizontally to switch between them.

Gallery

5. Gallery

All images generated in chat or Photo Mode are saved in the gallery. Press the 🖼 button in the header to open it.

Tap an image to view it full size. Delete unwanted images with the 🗑 button in the top right.

Gallery images are managed per character. Switching to a different character will show that character's images.
Sessions

6. Session Management

NookResonance manages conversations in units called "sessions." Switching sessions lets you enjoy conversations from different timelines.

Starting a New Session

Tap the session name in the header to open the session panel. Create a new one with ＋ New Session.

Session Handover

When a session approaches its turn limit, you will be prompted to hand it over. The AI summarizes the session and automatically creates a bridge message to carry into the next session.

1
Start handover Press the Handover button in the session panel.
2
Review and edit Check the AI-suggested summary, memories, and opening message for the next session. You can edit them if needed.
3
Resume in a new session A new session carrying over the handover content is created automatically.
Advanced

7. Advanced Features

Users granted "Advanced" permission by an admin can change detailed image generation settings per character.

Changing these settings can significantly alter the style of generated images. If you are unsure, leave the default values as they are.

Workflow Settings

When you open the character edit form, a Workflow selector appears at the top. Use it to switch the image generation model and style.

LoRA Settings

Below the workflow selector there is a LoRA settings section. Add LoRAs to reinforce a specific style or character.

1
Choose a LoRA Select a LoRA file from the dropdown.
2
Set strength Adjust model strength and CLIP strength with sliders (typically 0.7–1.0 is a good range).
3
Save Press Save at the bottom of the form to confirm.

Quality Tags / Negative Prompt

You can set quality enhancement tags and negative prompts (elements to exclude) per character.

Quality Tags typically contain image quality boosters like masterpiece, best quality,. Negative Prompt typically contains tags to exclude low quality output like worst quality, blurry,.
Account

8. Account Settings

Change Your Password

1
Open Settings Press the ⚙ button in the header.
2
Choose "Change Password" The "Change Password" section is inside the settings panel.
3
Enter your current and new password, then save The new password takes effect from your next login.
Passwords cannot be viewed by anyone, including admins. If you forget yours, ask your admin to reset it.
